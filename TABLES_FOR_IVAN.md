# Report tables and figures: layout for review (for Ivan)

What each table and figure in the midway report contains, which experiment fills it, and which research question
(RQ, as labeled in SPEC.md §7) it answers. Generated by `make report` into `report/tables/*.tex` and
`report/figures/*.pdf`; compiled preview in `report/preview.pdf`.

Conventions everywhere: `\tbd` (gray dash) = not run yet, never a placeholder number. Each number has a 95% bootstrap
CI over prompts, shown as ±half-width. Rates (% valid, % stable) are over all evaluated prompts; stability, CLIP and
DINO are over valid builds only; shape statistics are over all parsed builds. Stability is raw (1 − stress;
upstream caps stress at 1, so raw = clipped). Each column states the actual n of prompts it used.

**Please check:** row/column choices, model names, and the open questions at the end. Layout changes are cheap now.

## Table 1: Replication (baseline), `table1_replication.tex`, spans both columns

- **Answers:** does our BrickGPT setup reproduce the paper? (the handout's required baseline result)
- **Columns:** the three BrickGPT decoding settings: No RS, no RB · RS only · RS + RB. A header row under each
  column gives the prompt set, n and seeds actually used.
- **Rows:** % valid · % stable · mean stab. · min. stab. · CLIP · DINO · rollbacks (median) · sec. per build (median).
- **Cells:** `paper / ours±CI`; `n/r` = not reported in the paper.
- **Filled by:** Megha's runs `norsnorb_*`, `rs_*`, `full_*` (Ivan's Colab No RS/no RB run counts as `norsnorb_*`).
- **Now:** paper values only; all "ours" `\tbd`. CLIP/DINO stay `\tbd` for the midway (rendering is too slow here).

## Table 2: Main comparison, `table2_main.tex`, spans both columns

- **Answers:** RQ2 / RQ3 (SPEC §7.2).
